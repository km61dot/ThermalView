# ThermalView

ThermalView — минималистичное iOS-приложение для просмотра официального теплового состояния iPhone.

Приложение использует `ProcessInfo.thermalState`, поэтому показывает не температуру в градусах, а системный уровень iOS:

- **Норма** — устройство работает без тепловых ограничений.
- **Тепло** — нагрузка есть, но состояние ещё стабильное.
- **Горячо** — iOS может снижать производительность.
- **Критично** — лучше остановить нагрузку и охладить устройство.

## Сборка IPA

GitHub Actions собирает неподписанный IPA. Подпись выполняется отдельно в ESign личным сертификатом.

1. Открой вкладку **Actions**.
2. Запусти workflow **Build Unsigned IPA** или дождись запуска после push в `main`.
3. Скачай артефакт `ThermalView-unsigned-ipa`.
4. Импортируй IPA в ESign, подпиши и установи на iPhone.

## Технически

- SwiftUI
- iOS 17+
- Bundle ID: `com.km61dot.thermalview`
- CI: тесты + Release-сборка + проверка, что IPA неподписан

# Инструкция ThermalView

## Что делает приложение

ThermalView показывает тепловое состояние iPhone по официальному значению iOS `thermalState`. Это не градусы Цельсия. Apple отдаёт только уровни состояния устройства.

## Как собрать IPA через GitHub

1. Открой репозиторий `ThermalView`.
2. Перейди в **Actions**.
3. Выбери **Build Unsigned IPA**.
4. Нажми **Run workflow**.
5. После успешной сборки скачай артефакт **ThermalView-unsigned-ipa**.
6. Внутри будет `ThermalView-unsigned.ipa` и файл SHA-256.

## Как установить через ESign

1. Открой ESign.
2. Импортируй `ThermalView-unsigned.ipa`.
3. Выбери свой личный сертификат iDev.
4. Подпиши приложение.
5. Установи на iPhone.

## Если сборка не прошла

- Если ошибка в XcodeGen — проверь `project.yml`.
- Если ошибка в тестах — смотри блок **Run unit tests**.
- Если не найден `ThermalView.app` — измени путь поиска в workflow только после проверки названия схемы и target.
- Если IPA оказался подписанным — workflow специально остановится, потому что для ESign нужен неподписанный IPA.

## Ограничения

ThermalView не измеряет температуру в градусах и не имеет доступа к внутренним датчикам температуры. Это ограничение iOS, а не ошибка приложения.
